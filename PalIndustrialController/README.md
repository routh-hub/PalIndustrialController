# 帕鲁工业总控

《幻兽帕鲁》Steam 版 1.0.5.102999 的独立 UE4SS Lua MOD。面板在游戏里显示公会仓库库存、排队中的成品、设备上待搬走的产物，以及各项库存目标。

## 使用

1. 进入本机单人世界或自己开的房主世界，按 `Ctrl+F10` 打开面板。
2. 按 `Ctrl+F`，输入中文物品名或物品 ID，再按 `F4` 应用。清空搜索词后按 `F4` 可显示全部物品。
3. 用 ↑ / ↓ 选中物品，按 `Ctrl+G` 输入目标数量，再按 `F4` 保存。输入 0 会清除目标。目标会按存档和公会分别保存。
4. 进入有生产设备的据点，在面板内按 `F4` 启动补货。每 8 秒读取一次库存，按优先缺口安排生产或调拨原料。关闭面板后补货继续运行。再次打开面板并按 `F4` 可以暂停。

面板打开或自动补货运行时，MOD 每 8 秒重新读取当前公会的据点、普通物品箱和原版配方生产设备。建造完成并登记后，新设施会自动参与补货。拆除或迁出的设施会自动退出计划。重新打开面板也会立即读取。原有库存目标随存档和公会保留，可以在扩建后继续使用。

补货使用原版配方和设备，受配方的每批产量约束。系统跟踪尚未进入仓库的订单，包括帕鲁已经取走、仍在搬运的成品。订单从队列消失后若持续 90 秒未确认入库，系统会在设备已拆除时重新规划，在设备仍存在时暂停补货。确认仓库和设备情况后，可以按 `F4` 重新开始。自动下单时会尝试启用所选设备的「搬运到仓库」设置，由原版帕鲁分工生产和搬运。

当前的生产下单范围是角色所在据点。材料可从同公会其他据点调拨。角色离开生产据点后，原版已接受的订单继续按游戏规则运转，新的补货订单等待角色进入能接单的据点。跨据点远程下单和 MOD 自主改派帕鲁仍在开发。

## 安装

已安装 UE4SS Experimental 的 Steam 创意工坊版时，将整个 `PalIndustrialController` 文件夹放入 `Palworld/Mods/NativeMods/UE4SS/Mods/` 后启动游戏。保留该文件夹中的 `enabled.txt`。 [Pocketpair 的 MOD 加载路径文档](https://github.com/pocketpairjp/PalworldModUploader/blob/main/PalworldModUploader/docs/en/04-Tech.md)

运行日志位于 UE4SS 目录的 `UE4SS.log`，可搜索 `PalIndustrialController`。
