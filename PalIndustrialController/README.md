# 帕鲁工业总控

## 安装与升级

以 Windows Steam 版《幻兽帕鲁》1.0.5.102999、UE4SS Experimental (Palworld) `2281fa31` 为目标环境。推荐先在复制的隔离存档验收候选版。实测范围和待验收项见 `docs/TEST_REPORT.md` 与 `docs/HANDOFF.md`。

1. 关闭游戏。备份 `%LOCALAPPDATA%\Pal\Saved\SaveGames` 和已安装的整个 `PalIndustrialController` 文件夹。
2. 在 Steam 创意工坊安装并启用 [UE4SS Experimental (Palworld)](https://steamcommunity.com/sharedfiles/filedetails/?id=3625223587)。
3. 将安装包中的 `PalIndustrialController` 放入游戏目录的 `Mods/NativeMods/UE4SS/Mods/`，保留 `enabled.txt`。升级时，将上一步备份内的 `targets-*.tsv` 和 `orders-*.tsv` 及其 `.previous`、`.tmp` 文件复制到对应位置。每次只安装一份工业总控。
4. 进入世界后按 `Ctrl+F10` 打开面板（若游戏正在运行，更新脚本后需要重启游戏才能加载新版）。打开面板后会自动显示鼠标并锁定游戏内按键，避免点击触发攻击、建造或交互；关闭面板后自动交还鼠标和游戏输入。日志位于 UE4SS 目录的 `UE4SS.log`，可搜索 `PalIndustrialController`。

## 界面鼠标操作（推荐）

- **打开与关闭**：按 `Ctrl+F10` 打开面板；点击右上角「关闭」或再按 `Ctrl+F10` / `Esc` 关闭。
- **切换页面**：直接点击左侧导航栏（首页 / 库存 / 生产作业 / 据点调拨 / 帕鲁顾问 / 库存趋势 / 设置）。
- **首页**：按状态显示「启动补货」或「暂停补货」按钮；有待核验订单时直接列出具体订单与「查看订单」按钮，进入生产作业/据点调拨页核对后点击「确认接管」。
- **库存**：页面顶部直接提供搜索框与「搜索」「清除」「显示：已设目标 / 全部物品」按钮；点击任意物品行，在右侧直接输入或点 `-10` / `+10` 调整目标数量并点「保存目标」。
- **设置**：直接点击每一项的开关、选项或「导出蓝图」按钮。
- **帕鲁顾问**：默认只按当前生产状态给出建议，不自动读取在岗帕鲁和帕鲁终端（避免触发实机崩溃）；仅在手动点击「尝试读取在岗帕鲁（高风险）」时才执行。

## 保留快捷键（可选）

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+F10` / `Esc` | 打开或关闭面板（输入文字时 `Esc` 不直接关窗） |
| `Enter` / `F4` | 文本框聚焦时确认搜索或保存目标；无焦点时 `F4` 启动/暂停补货 |
| `←` / `→`、`Ctrl+F9` | 切换页签；`Home` 返回首页 |
| `↑` / `↓`、`PgUp` / `PgDn` | 选择项目或翻页 |
| `Ctrl+F` / `Ctrl+G` | 聚焦库存搜索框 / 目标输入框 |
| `Ctrl+Home` | 库存页清除搜索或切换已设目标 / 全部物品 |
| `Ctrl+←/→`、`Ctrl+Shift+←/→` | 库存页快速增减目标 ±10 / ±100；设置页调整当前选项 |
| `Ctrl+E` / `Ctrl+D` | 帕鲁顾问页切换策略 / 展开收起高级建议 |
| `Ctrl+F8` | 设置页导出蓝图；顾问页手动尝试读取在岗帕鲁 |
| `Ctrl+Shift+R` | 暂停状态下确认接管待核验订单 |

## 机制与边界说明

- **动态据点与库存账本**：面板打开或补货运行时每 8 秒扫描同公会已登记据点、普通仓库与配方设备。据点数量随原版公会列表动态增减。
- **执行边界**：生产请求与调拨目的地限定在本地权威玩家所在据点；可在当前据点递归生产另一据点所需的上游中间品。
- **暂停、恢复与回滚**：
  - `?` 表示待核验数量未知，人工核验标记持久化到第二版任务日志（兼容读取第一版），重启仍保持暂停；核对物资去向后点击「确认接管」再启动补货。
  - 禁用或卸载：先暂停补货并关闭游戏，将 `PalIndustrialController` 移出 `UE4SS/Mods/` 即可，原版已受理队列随存档保留。
  - 回滚到更早版本：先核对并接管全部待核验订单后关闭游戏，还原备份存档或仅迁移 `targets-*.tsv`。
